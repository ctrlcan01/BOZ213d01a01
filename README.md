# Tek ve Çift Sayı Kontrol Programı 🧮

Bu proje, Python'a giriş ve temel algoritma mantığını anlamak için geliştirilmiş basit bir konsol uygulamasıdır. Kullanıcıdan alınan bir sayının tek mi yoksa çift mi olduğunu matematiksel operatörler (`%`) kullanarak hesaplar.

## Özellikler
- Temel `if-else` koşul yapıları kullanılmıştır.
- `try-except` bloğu ile hatalı girişler (harf girilmesi vb.) kontrol altına alınmıştır.

## Nasıl Çalıştırılır?
1. Bilgisayarınızda Python'un kurulu olduğundan emin olun.
2. Proje dosyalarını bilgisayarınıza indirin.
3. Terminal veya Komut İstemcisi üzerinden dosyanın bulunduğu dizine gidin.
4. Şu komutu çalıştırın:
   ```bash
   python tek_cift_bulucu.py
